# Photon Browser v1.0.4

## 🐛 **Bug Fixes**

This release includes various bug fixes and improvements to enhance stability and user experience.

### **Improvements**
- **Screenshot Format**: Converted all screenshots to PNG format for better quality and compatibility
- **Image References**: Updated README to use PNG images throughout
- **Code Quality**: General code improvements and stability enhancements

## 📦 **What's Included**

- Complete app bundle with executable, icon, and Info.plist
- All features from v1.0.3
- Updated screenshots in PNG format
- Bug fixes and stability improvements

## 📥 **Installation**

1. Download `Photon-v1.0.4-macOS.zip` from the releases page
2. Extract the zip file
3. Move `Photon.app` to your Applications folder
4. Double-click to launch

## 🎯 **The Photon Experience**

Experience browsing without the browser. Photon fades into the background, giving you pure focus on what matters: your web content.

**The best interface is #NoInterface.**
