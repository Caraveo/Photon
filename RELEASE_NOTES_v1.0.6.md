# Photon Browser v1.0.6

## 🎨 **UI Enhancements & Visual Polish**

### **Favicon Support in Tabs**
- **Website favicons now display in tabs** - See each site's icon for quick visual identification
- **Smart favicon extraction** - Automatically detects and loads favicons from multiple sources:
  - Checks for `<link rel="icon">` tags
  - Tries common favicon paths (`/favicon.ico`, `/favicon.png`)
  - Falls back gracefully to globe icon if favicon unavailable
- **Optimized display** - Favicons are automatically resized to 16x16 for consistent tab appearance

### **Transparent Toolbar & Scrollbars**
- **Transparent toolbar** - Tab bar now blends seamlessly with content
- **Transparent scrollbars** - Web content scrollbars fade into background
- **#NoInterface refinement** - Even cleaner, more minimal browsing experience

### **Window Title Removed**
- **No window title** - Removed "Photon" from window title bar
- **Cleaner interface** - App name appears in Apple menubar only
- **More screen space** - Focus entirely on web content

## 🐛 **Bug Fixes**
- Fixed settings persistence issues
- Improved favicon loading reliability
- Enhanced scrollbar transparency implementation

## 📦 **What's Included**

- Complete app bundle with executable, icon, and Info.plist
- **Properly signed** with Developer ID Application certificate
- All features from previous versions
- Enhanced visual polish and UI refinements

## 📥 **Installation**

1. Download `Photon-v1.0.6-macOS.zip` from the releases page
2. Extract the zip file
3. Move `Photon.app` to your Applications folder
4. Double-click to launch

### **If You See a Security Warning**

If macOS shows a "not free of malware" or "cannot be opened" warning:

1. Go to **System Settings** → **Privacy & Security**
2. Scroll down to find **Photon** in the list
3. Click **Open Anyway** or **Allow**

Alternatively, right-click `Photon.app` and select **Open** (first time only).

**Note**: Photon is properly code-signed with Developer ID. This warning may appear for apps not distributed through the App Store, but the app is safe to use.
